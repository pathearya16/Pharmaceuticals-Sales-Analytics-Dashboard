# 🏥 Pharmaceutical Sales Analytics Dashboard

The **Pharmaceutical Sales Analytics Dashboard** is an interactive business intelligence solution developed using **Power BI** to analyze pharmaceutical sales data from **2014 to 2019**.

---

## 📌 2. Project Description

This project focuses on analyzing pharmaceutical sales data to understand **sales trends**, **seasonal demand patterns**, and **category-wise performance**.  
The goal is to transform raw sales data into meaningful insights that support **better decision-making**, **demand forecasting**, and **inventory planning**.

---

## ⚙️ 3. Tech Stack

The dashboard was built using the following tools and technologies:

- 📊 **Power BI Desktop** – Dashboard development & visualization  
- 📂 **Power Query** – Data cleaning and transformation  
- 🧠 **DAX** – Calculated measures and business logic  
- 🗃️ **File Format** – `.pbix` (development), `.png` (dashboard previews)  
- 📝 **Data Modeling** – Relationships between tables for cross-filtering  

---

## 📊 4. Data Source

- The dataset is a structured pharmaceutical sales dataset covering **2014–2019**, stored in **Excel/CSV format**  
- Each record represents a sales transaction with fields like **date** and **drug category (ATC classification)**  
- The dataset contains a large number of records, making it suitable for **trend and seasonality analysis**  
- Data was cleaned and transformed using **Power Query**, including creation of additional fields such as **year, month, and week**  
- The processed data was used to analyze patterns, evaluate category performance, and perform **short-term forecasting**

---

## 🚀 5. Features

- 📌 **KPI Cards** – Total Sales, YoY Growth, Previous Year Sales  
- 📈 **Trend Analysis** – Monthly & yearly sales trends  
- 🔄 **Year-wise Filtering** – Interactive slicers (2014–2019)  
- 🧪 **Category Analysis** – Top-performing drug categories  
- ⏱️ **Seasonality Analysis** – Peak demand periods  
- 🔮 **Forecasting** – Next 2 weeks sales prediction  
- 📊 **Interactive Dashboard** – Dynamic and user-friendly visuals  

---

## 🎯 6. Highlights

- **Problem**  
  Pharmaceutical sales data is large and complex, making it difficult to identify trends, seasonal demand, and top-performing categories.

- **Goal**  
  To analyze the dataset and extract insights such as **sales trends**, **peak demand periods**, **category performance**, and perform **short-term forecasting**.

- **Solution**  
  Developed an interactive **Power BI dashboard** using data cleaning, transformation, and DAX measures.  
  Visualizations like **KPI cards, line charts, bar charts, and donut charts** were used to present insights clearly, along with forecasting to predict future demand.

- **Impact**  
  Converted raw data into **actionable insights**, enabling better planning, forecasting, and decision-making.
