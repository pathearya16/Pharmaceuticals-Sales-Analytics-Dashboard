🏥Pharmaceuticals Sales Analytics Dashboard
The Pharmaceutical Sales Analytics Dashboard is an interactive business intelligence solution developed using Power BI to analyze pharmaceutical sales data from 2014 to 2019

2.Project Description
This project focuses on analyzing pharmaceutical sales data to understand sales trends, seasonal demand patterns, and category wise performance. The purpose is to convert raw sales data into meaningful insights that help in better decision making, demand forecasting, and inventory planning.

3.Tech Stack
The dashbaord was built  using the following tools and technologies:
• 📊Power BI desktop - Used for dashboard development & visualization.
• 📂Power Query - Data transformation and cleaning for reshaping and preparing data.
• 🧠DAX - Used for calculated measures and conditional logic.
• 🗃️File Format - .pbix for development and .png for dashbaord previews.
• 📝Data Modeling - Relationships established among tables to enable cross filtering.

4.Data Source
• The data used in this project is a structured pharmaceutical sales dataset covering the period from 2014 to 2019, stored in Excel/CSV format, where each record represents a sales transaction including fields such as date, drug category (ATC classification)
• The dataset contains a large number of entries, making it suitable for trend and seasonality analysis. 
• Before building the dashboard, the data was cleaned and transformed using Power Query, with proper formatting and creation of additional fields like year, month, and week for time-based analysis. 
• This prepared data was then used to analyze sales patterns, evaluate category performance, and perform short-term forecasting, helping generate meaningful insights for decision making.

5.Features
• 📌 KPI Cards – Total Sales, YoY Growth, Previous Year Sales
• 📈 Trend Analysis – Monthly & yearly sales trends
• 🔄 Year wise Filtering – Interactive slicers (2014–2019)
• 🧪 Category Analysis – Top-performing drug categories
• ⏱️ Seasonality Analysis – Peak demand months & patterns
• 🔮 Forecasting – Next 2 weeks sales prediction
• 📊 Interactive Dashboard – User-friendly and dynamic visuals

6.Highlights
• Problem Identification - The main problem was that pharmaceutical sales data was large and complex, making it difficult to identify trends, seasonal demand patterns, and top-performing drug categories for effective decision-making.
• Goal - The goal of this project was to analyze this data to uncover meaningful insights such as sales trends, peak demand periods, category performance, and to perform short-term forecasting.
• To achieve this, an interactive Power BI dashboard was developed using data cleaning, transformation, and DAX measures. Various visualizations like KPI cards, line charts, bar charts, and donut charts were used to represent the data clearly, along with forecasting to predict future demand. This helped convert raw data into actionable insights for better planning and decision-making.
